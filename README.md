# Generador de Correos

Página estática (`index.html`) que crea direcciones de correo temporales **reales** usando la API pública de [mail.tm](https://mail.tm): recibe mensajes en tiempo real, detecta códigos y enlaces de verificación, y guarda el buzón en el navegador.

No necesita build ni servidor. Para publicarla en Vercel: importa este repositorio en https://vercel.com/new con el preset **Other**.
